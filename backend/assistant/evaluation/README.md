# 评测资产

[开放问法盲测](generalization_live.py) 从工作台真实流式接口重放 12 个独立于生产提示词的问法，包括常识、写作、翻译、计算、追问、企业资料缺失、实时信息边界和跨业务查询。使用本机授权测试账号设置 `MES_TRACE_USER` 和 `MES_TRACE_PASSWORD` 后，从仓库根目录运行 `backend/assistant/rag/.venv/Scripts/python.exe backend/assistant/evaluation/generalization_live.py --out backend/assistant/rag/data/generalization-check`。业务题同时核对工具记录、正文与只读 MySQL 的库存及设备明细。用同样命令加 `--verify-only` 可在源记录未变时复核已保存的回执。题库的实时台账预期针对可见完整库房和设备的本机测试账号。

[工序问答与质检追溯验收](process-inspection.md) 记录了八道派工工序、精确检验单多轮追问、同批终检与复检比较，以及直接回查 MySQL 的复测步骤。

开放问法脚本增加 `--cases stock_handoff` 可单独检验同一会话内的业务改写。脚本先查一种物料，再核对追问是否带着原范围发起新的业务读取，并给出原库可复核的合计。这个附加用例单独记分。

2026-11-21 本机工作台盲测中，旧版通过 7/12。曾出现上一轮改写跑题、翻译和拟稿被拒、业务解释只剩表格标题，以及正文否认已有跨域记录。使用同一组问题复测，最终通过 12/12；附加的业务表改写通过 1/1。实际对照了 21 条库存记录和 26 台设备的 ID，复核全部库存行的物料名与可用量。缺少厂内手册或实时外部来源时，验收检查回答是否明确数据边界。

[联合检索验收与运维](federation.md) 记录了 30 道历史问题、三张授权订单的连续追问、四类数据路由及其可重复执行的核验命令。原始回执保存在本机忽略目录，避免提交账号信息和业务正文。

首批覆盖订单交付、共享库存归属不明、物料缺口、质量阻塞、售后断链、权限越界与缺失知识。真实业务数据需脱敏并单独管理，未经审核不转为微调样本。
